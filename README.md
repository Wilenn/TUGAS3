# Library OOP Mini

Project sederhana simulasi perpustakaan menggunakan PHP OOP.

## Fitur

- Membuat beberapa object Book
- Membuat object Member
- Menampilkan informasi buku
- Menampilkan informasi member
- Simulasi peminjaman buku
- Inheritance menggunakan DigitalBook

## Konsep OOP

Project ini menerapkan:

- Class
- Object
- Property
- Method
- Constructor
- `$this`
- Visibility
- Encapsulation
- Inheritance
- Namespace

## Struktur File

- `Book.php` - Class untuk data buku
- `Member.php` - Class untuk anggota dan peminjaman
- `DigitalBook.php` - Class turunan dari Book
- `index.php` - Menjalankan program

## Cara Menjalankan

1. Pastikan PHP sudah terinstall.
2. Buka terminal pada folder project.
3. Jalankan:

```bash
php -S localhost:8000
